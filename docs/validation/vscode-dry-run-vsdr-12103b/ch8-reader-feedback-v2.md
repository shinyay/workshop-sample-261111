## 2. 何を確認すれば終えてよいか

各条件の会話で、指定された絞り込みテスト、portal テスト、全体テスト、ruff、format、mypy の6つがすべて成功し、さらに確認担当が各最終コードで全体テスト・ruff・format・mypy を独立に再実行して同じ結果になれば、**比較の確認は終了**です。実ブラウザー確認は対象外として未実施と記録します。`ch8-sheet.md#L19`

修正の中心は、API の `count` と画面の結果件数を一覧の実数に合わせ、全申請総数・状態別集計は変えないことです。依頼は検索結果、単独・複合・0件、UI/API、既存操作の維持も求めています。`ac.md#L14` `ab-conditions.md#L13`
